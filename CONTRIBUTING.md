# Contributing

Thanks for your interest in the Command Pattern Simulator.

## Contribution guidelines

- Keep pull requests focused and easy to review.
- Do not commit real credentials, tokens, or production data.
- Preserve the simulator's safe, local behavior.
- Add or update tests when behavior changes.
- Keep TypeScript and build checks passing.

## Pull requests

Please include:

1. A concise description of the change.
2. Why it is useful.
3. How you tested it.
4. Any risk or rollback note when relevant.

Documentation, accessibility, test coverage, and focused architecture improvements are welcome.
